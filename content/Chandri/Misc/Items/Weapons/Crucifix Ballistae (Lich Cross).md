### Overview
- Damage: 2d10
- Range: 400-800ft
- Special Properties:
	- Requires a set up action - tripod
- Weight: 40lbs

### Description:

> This heavy, entirely steel-wrought crossbow is so large it’s more of a small ballista, and it uses a set of steel gears and cranks to draw the firing string. Its firing beams are long and the weapon generally shaped like a large metal crucifix, symbolizing the torturous punishment for creatures who attempt to escape their mortality. This weapon must be set up before it can be fired and setting up this weapon requires the user to use an action to put down a firing tripod to support the weapon while it’s fired. Once it is set up, the weapon cannot be easily moved, as it weights 40lbs. Otherwise, this ranged weapon has the properties of a heavy crossbow, except that it has a range of 400/800ft deals 2d10 piercing damage. The loading property of this weapon cannot be circumvented.
